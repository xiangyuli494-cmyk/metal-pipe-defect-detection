# 金属细管内壁缺陷检测系统 · 用户操作手册

> 适用版本：v1.0 · 2026-09

---

## 1. 系统简介

本系统面向金属细管（管径 4–20mm）内壁微缺陷检测场景，提供：

- 单张图片检测
- 批量图片检测
- 摄像头实时检测
- 视频文件检测
- 检测历史查询与统计
- 多用户、多角色权限管理
- AI 模型热切换

## 2. 启动系统

### Windows

```cmd
:: 双击
start.bat
```

启动成功后会自动打开浏览器，访问 `http://localhost:3015`。

### Linux / macOS

```bash
chmod +x start.sh stop.sh
./start.sh
```

## 5. 核心操作

### 5.1 单张检测

1. 进入「单张检测」页面。
2. 拖拽或点击上传 1 张内窥镜截图（支持 jpg/png/bmp，最大 10MB）。
3. 等待 ~200ms，AI 返回：
   - 标注后的结果图（缺陷位置彩色框）
   - 缺陷列表：类别、置信度、坐标、宽高
   - 处理耗时
4. 可点击「下载报告」保存 CSV 或 JSON。

### 5.2 批量检测

1. 进入「批量检测」页面。
2. 选择文件夹或拖拽多张图片。
3. 设置置信度阈值（默认 0.5）和 IOU 阈值（默认 0.45）。
4. 点击「开始批量检测」，进度条实时刷新。
5. 完成后生成批量报告，列出每张图、每条缺陷。
6. 一键导出 CSV / JSON。

### 5.3 摄像头实时检测

1. 进入「摄像头检测」页面，授权浏览器使用摄像头。
2. 选择 USB 内窥镜 / 工业相机 / 笔记本自带摄像头。
3. 系统自动开始推理，缺陷框实时叠加。
4. 可开启「自动告警」：当某类别置信度 > 阈值时自动截图 + 通知。
5. 会话结束后，可在「历史 → 摄像头」中查看录像回放。

### 5.4 视频文件检测

1. 进入「视频检测」页面。
2. 上传 mp4/avi/mov（最大 50MB，更大请修改 `nginx.conf`）。
3. 设置帧间隔（默认 10，即每 10 帧检测一次）。
4. 系统后台抽帧 + 推理，进度条更新。
5. 完成输出 JSON（每帧检测结果）+ 可视化视频。

### 5.5 历史与统计

- **历史**：支持按时间区间、检测类型、用户、文件名筛选；点击单条进入详情可看原图 + 结果图。
- **统计**：折线图（每日检测量）、饼图（缺陷类别分布）、柱状图（用户排行）。

### 5.6 模型管理（admin）

1. 进入「系统设置 → 模型管理」。
2. 点击「上传模型」，选择 `.pt`/`.onnx`/`.pb` 文件。
3. 上传成功后点击「激活」按钮，AI 推理立即切换到新模型（无需重启）。
4. 可重命名、编辑类别名、删除不需要的模型。

## 6. 系统设置（admin）

- **检测参数**：默认置信度阈值 / IOU 阈值 / 最大文件大小。
- **通知**：是否启用邮件 / 站内通知。
- **存储**：上传路径、保留天数、自动清理。
- **安全**：JWT 密钥、Token 过期时间、登录失败锁定。

## 7. 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 启动报 `ModuleNotFoundError` | 依赖未装全 | 删除 `venv/`，重新跑 `start.bat` |
| 后端 `Connection refused :8002` | 端口被占 | `netstat -ano | findstr :8002` 杀掉占用进程 |
| 摄像头黑屏 | 浏览器非 https / 非 localhost | 用 `http://localhost:3015` 访问，或配置 HTTPS |
| AI 推理慢 | 没用 GPU | 安装 CUDA 版 torch，或减小 imgsz |
| 模型加载失败 | .pt 与 torch 不匹配 | 升级 `pip install -U ultralytics torch` |
